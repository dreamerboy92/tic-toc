# ❌⭕ Tic-Tac-Toe Game in Python

This is a simple **Tic-Tac-Toe (X-O)** game written in Python. It is a two-player game played on the terminal. Players take turns to mark `X` and `O` on a 3x3 grid until one wins or the game ends in a draw.

---

## 🧠 How the Game Works

- The board has 9 positions numbered **1 to 9**.
- Two players take turns to place `X` or `O`.
- The first player to align **3 symbols** (horizontally, vertically, or diagonally) wins.
- If all positions are filled without a winner, the game ends in a **draw**.

---

## 💻 Technologies Used

- Python 3.x
- No external libraries required
- Uses only built-in functions, loops, and conditionals

---

## 📋 Features

✅ Two-player support  
✅ Terminal-based user interface  
✅ Detects winning condition or draw  
✅ Clean and readable code
